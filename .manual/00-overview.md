# 00. 서비스 전체 개요

## 서비스 정의

DotLink는 숏폼 크리에이터가 성공한 콘텐츠의 구조를 분석하고, 그 요소를 재조합하여 새로운 대본을 설계할 수 있는 AI SaaS 도구입니다.

## 핵심 가치 제안

> "좋은 예술가는 베끼고, 위대한 예술가는 훔친다"
> 성공한 콘텐츠의 DNA를 해독하고, 나만의 창작물로 재탄생시키세요.

## 사용자 플로우

```
1. 회원가입/로그인
       ↓
2. 숏폼 URL 입력 (인스타그램/틱톡/유튜브)
       ↓
3. AI DNA 분석 (9가지 차원)
   - 3초 후킹 영상 요소
   - 3초 후킹 텍스트 요소
   - 전체 스크립트 매력도
   - 캡션 분석
   - 영상미/연출
   - 인게이지먼트 장치
   - 콘텐츠 유형 분류
   - 세일즈/소구점
   - 제작 난이도 (기획/촬영/편집)
       ↓
4. 라이브러리에 저장
       ↓
5. 시냅스: 두 콘텐츠 비교 + Creation Card 작성
       ↓
6. 대본 완성 & 내보내기 (향후)
```

## 타겟 사용자

- 인스타그램/틱톡/유튜브 숏폼 크리에이터
- 브랜드 마케터 & 에이전시
- 1인 미디어 도전 직장인

## 요금제 구조

| 플랜 | 가격 | 핵심 제한 |
|---|---|---|
| Starter | 무료 | 월 5회 분석, 라이브러리 최대 10개 |
| Creator | ₩29,000/월 | 월 50회 분석, 무제한 저장 |
| Pro | ₩59,000/월 | 무제한 분석, 팀 협업 5명 |

## 기술 아키텍처 요약

```
클라이언트 (Next.js)
    ↓ API Route
서버 (Next.js API)
    ├── 인증: Supabase Auth
    ├── DB: Supabase PostgreSQL
    └── AI 파이프라인:
        Apify (크롤링) → Whisper (음성→텍스트) → Gemini (분석)
```
